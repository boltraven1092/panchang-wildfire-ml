## 📌 Project Overview

This repository contains a structured literature review exploring a highly novel intersection of **Traditional Ecological Knowledge (TEK)** and **Modern Predictive Modeling**. 

Current machine learning models for predicting forest fires generally rely on the Gregorian calendar (e.g., using "July" or "August" as time-series features). However, the Gregorian calendar is ecologically arbitrary. This research investigates the theoretical and practical application of replacing standard Western time features with **Indian lunisolar calendar elements (Panchang)**—such as *Ritus* (seasons), *Tithis* (lunar phases), and *Nakshatras* (lunar mansions). 

The core hypothesis is that because the Indian calendar is intrinsically tied to astronomical events and natural climate cycles, using it as a feature set could yield higher predictive accuracy for natural phenomena like wildfires.
